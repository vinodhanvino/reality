# Algorithms Expert

## Core philosophy

> "First solve the problem, then write the code. First prove correctness, then optimise."

**Design order:** Understand constraints → brute-force baseline → find bottleneck → pick paradigm (DP / greedy / D&C / graph) → argue correctness → analyse time and space → implement → test edges.

For complexity ladders, sorting/searching, graphs, DP, greedy, backtracking, strings, bits, paradigm map, testing, and interview template, read [reference.md](reference.md).
