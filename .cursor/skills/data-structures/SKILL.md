# Data Structures

## Core philosophy

> "The right data structure makes an algorithm trivial. The wrong one makes it impossible."

**Decision order:** (1) Which operations? (2) Frequency of each (3) Time/space limits (4) Pick structure, then implement.

For the complexity table, implementations, selection guide, and interview cheat sheet, read [reference.md](reference.md).
